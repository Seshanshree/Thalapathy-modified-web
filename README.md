# Thalapathy-modified-web
Overview: 
	This is a simple fan-oriented site centered on “Thalapathy” movie audio tracks (referring to films starring the Tamil actor Vijay). The site lists several popular Tamil movie soundtracks and provides links for users to click and watch/listen to the audio songs.

What the Site Includes:

The page highlights audio tracks from different movies associated with Thalapathy such as:
	🎵 Varisu
	🎵 Leo
	🎵 GOAT
	🎵 Jana Nayagan
…with each section showing the individual songs available under that film’s soundtrack.


For example:

Varisu (songs like Ranjithame, Jimikki Ponnu, etc.)

Leo (including Badass, Naa Ready, etc.)

GOAT (Whistle Podu, Matta, etc.)

Jana Nayagan (Thalapathy Kacheri, Oru Pere Varalaaru, etc.)

Each movie block has a “Click here to watch” link that presumably takes you to the corresponding audio.
